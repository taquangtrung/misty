# Changelog

Notable changes to misty are recorded here from 0.1.0 on, in the format of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/): one line per change, saying what changed for an app author and linking to the docs for the rest, and every breaking change under **Changed** or **Removed** with what to use instead.

Before 0.1.0 the API changes freely and changes are not listed; the git history records them. A major version bump of `wgpu` or `accesskit`, which misty re-exports, is a misty breaking change.
